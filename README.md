# Gabriel Castellon · Portfolio

Welcome! This is my personal corner of the web, sharing my projects, work
experience, and interests in computer science, neuroscience, and mathematics.

Built with **Astro**, **Tailwind CSS**, and a little **React**, with local Markdown
content and static hosting on **Vercel**.

## Projects

- **Shoe Marketplace** — a MERN web application for creating shops and listing footwear.
- **Android Navigation App** — a Kotlin app built in Android Studio with Google Maps API and a database.

## Run locally

Requires Node.js 22.22 or newer.

```sh
npm ci
npm run dev -- --background
```

Use `npm run build` for a production build and `npm run check` for code checks.
